# 🎓 Student Management System

A simple **CRUD-based Student Management System** built to practice frontend development using React.

---

## 🚀 Live Demo
👉 https://student-management-system-six-mu.vercel.app/

---

## 📌 About the Project

This project is a **basic CRUD application** created for learning purposes.  
It focuses on understanding how to manage state and perform Create, Read, Update, Delete operations in a frontend application.

---

## ✨ Features

- ➕ Add new students
- 📋 View student list
- ✏️ Edit student details
- ❌ Delete students
- 💾 Simple state management (frontend only)

---

## 🛠️ Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite / React tooling

---

## 🎯 Purpose

This project was built to practice:
- CRUD operations
- Component-based architecture
- State management in React
- UI handling and form logic

It is NOT a production system — just a learning project.
